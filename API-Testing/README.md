# API Testing – JSONPlaceholder

## Project Overview

This project demonstrates API testing using Postman and JSONPlaceholder.

## Tools Used

- Postman
- JavaScript
- GitHub

## Testing Performed

- GET API testing
- POST API testing
- Positive testing
- Negative testing
- Status code validation
- Response body validation
- Environment variables
- Automated assertions

## API Tested

JSONPlaceholder User API

## Test Scenarios

- Verify existing user returns 200 OK
- Verify correct user ID is returned
- Verify email format
- Verify user name is present
- Verify non-existing user returns 404
- Verify non-existing user returns an empty response
- Verify new user creation returns 201 Created
