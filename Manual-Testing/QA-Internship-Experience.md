# QA Internship Experience

## Overview

During my QA internship, I gained practical experience in software testing and learned how to approach applications from a quality assurance perspective.

## Responsibilities & Activities

* Performed manual functional testing of web application features
* Created and executed test cases
* Designed test scenarios based on application requirements
* Performed positive and negative testing
* Tested login and registration functionality
* Performed input validation testing
* Applied Boundary Value Analysis (BVA)
* Identified and documented software defects
* Assigned severity and priority to defects
* Performed regression testing after fixes
* Verified expected and actual results
* Reported defects with clear reproduction steps
* Practiced systematic test execution and documentation
