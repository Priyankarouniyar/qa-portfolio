# Manual Testing Project

## Project Overview

This project demonstrates practical manual software testing activities performed on a web application.

The project covers test scenario creation, test case design, functional testing, negative testing, boundary value analysis, bug reporting, and test execution.

## Testing Objectives

* Understand the software requirements
* Create test scenarios and test cases
* Perform functional testing
* Perform positive and negative testing
* Identify and document defects
* Apply Boundary Value Analysis
* Execute test cases and record results

## Testing Types

* Functional Testing
* Positive Testing
* Negative Testing
* Boundary Value Analysis
* Validation Testing
* UI Testing

## Test Documentation

The project will contain:

* Test Scenarios
* Test Cases
* Bug Reports
* Test Execution Report
* Test Evidence / Screenshots
