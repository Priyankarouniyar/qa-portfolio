# SQL Testing – QA Portfolio

## Project Overview

This project demonstrates practical SQL testing skills used by Software QA Engineers to verify and validate data stored in a database.

The project focuses on writing SQL queries, validating database records, checking data accuracy, and performing basic database testing.

## Objectives

* Understand database testing concepts
* Write SQL queries for data validation
* Verify inserted and updated records
* Validate deleted records
* Check data using conditions
* Identify duplicate records
* Perform positive and negative database testing
* Document SQL test cases and results

## SQL Concepts Covered

* SELECT
* INSERT
* UPDATE
* DELETE
* WHERE
* ORDER BY
* GROUP BY
* HAVING
* COUNT
* Duplicate data validation

## Testing Activities

* Verify user records
* Validate inserted data
* Verify updated data
* Verify deleted data
* Search records using conditions
* Check duplicate records
* Validate database results against expected results

## Tools

* MySQL
* MySQL Workbench / phpMyAdmin
* SQL
